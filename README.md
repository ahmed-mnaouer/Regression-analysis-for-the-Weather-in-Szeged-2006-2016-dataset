# 🌤️ Humidity Prediction using Regression Analysis

This project focuses on predicting humidity levels using regression techniques, based on the **Weather in Szeged (2006–2016)** dataset.

## 📈 Project Overview

The goal of this project was to build and evaluate multiple regression models to predict humidity based on various weather variables such as apparent temperature, wind speed, hour, and month.

> 🕐 **Note**: This entire project — from data preparation to final reporting — was completed in **one day only**, making it a challenging yet insightful experience!

## 🔍 Key Steps

- ✅ **Data Cleaning & Preprocessing**  
  Handled missing values, outliers, and irrelevant columns.

- 📊 **Exploratory Data Analysis (EDA)**  
  Explored relationships between features and target variable (humidity) using correlation matrices, scatter plots, and boxplots.

- 🧠 **Regression Modeling**
  - **Multiple Linear Regression**: Achieved an Adjusted R² of **0.46**
  - **Polynomial Regression (degree = 5)**: Achieved a higher Adjusted R² of **0.67**

- 🧪 **Model Evaluation**
  - Compared performance metrics
  - Checked for multicollinearity and evaluated assumptions (LINE: Linearity, Independence, Normality, Equal variance)

## 🧩 Key Takeaways

- A more interpretable model (linear regression) was selected over the more complex polynomial model.
- Assumption testing was crucial to understanding the reliability of the models.
- A fast-paced timeline taught the importance of prioritizing clarity and feasibility in analysis.
